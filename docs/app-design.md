# JoyVet App 设计方案

## 一、产品定位

### 1.1 产品愿景
**让每只宠物都能享受专业、透明、便捷的医疗服务**

### 1.2 产品定位
JoyVet 是一款**专注宠物医疗健康**的移动应用，为宠物主人提供：
- 🏥 在线问诊与线下预约
- 📋 全生命周期健康档案
- 💊 智能健康管理
- 🔍 透明化医疗服务

### 1.3 产品原则
1. **专业至上**：医疗服务质量第一
2. **透明化**：价格、资质、评价全公开
3. **简单易用**：功能聚焦，避免臃肿
4. **值得信赖**：建立可靠的信任机制

### 1.4 目标用户
- **主要用户**：25-35岁宠物主人，一二线城市
- **次要用户**：三四线城市宠物主人，需要远程医疗
- **潜在用户**：准备养宠人群

### 2.2 核心功能详细设计

#### 2.2.1 在线问诊

**图文问诊流程：**
1. 选择宠物（从健康档案）
2. 选择科室（内科、外科、皮肤科等）
3. 描述症状
   - 文字描述
   - 上传照片/视频
   - 症状持续时间
   - 既往病史（自动关联）
4. 选择医生（可选）
   - 系统智能推荐
   - 手动选择
5. 支付问诊费
6. 医生接诊
   - 医生询问补充信息
   - 医生给出诊断建议
   - 开具处方（如需）
7. 评价反馈

**视频问诊流程：**
- 类似图文问诊，但采用实时视频通话
- 适合需要观察宠物状态的场景
- 价格略高于图文问诊

**紧急咨询：**
- 7×24小时值班医生
- 快速响应（5分钟内）
- 给出紧急处理建议或转诊指引

#### 2.2.2 预约挂号

**预约流程：**
1. 选择医院
   - 地图模式：显示附近医院
   - 列表模式：筛选排序
   - 显示医院信息：
     - 资质认证标识
     - 用户评分
     - 距离
     - 科室列表
     - 价格区间
2. 选择科室
3. 选择医生
   - 医生照片、姓名、职称
   - 资质证书（可查看）
   - 擅长领域
   - 用户评价
   - 接诊量
   - 可预约时间
4. 选择时间
   - 日历视图
   - 显示可预约时段
5. 填写就诊信息
   - 选择宠物（自动带出病史）
   - 症状描述
   - 联系方式
6. 确认预约
   - 显示预约单详情
   - 价格明细（挂号费、诊疗费预估）
7. 支付/预约成功
8. 接收提醒通知

**预约管理：**
- 待就诊
- 已就诊
- 已取消
- 取消/改约功能

#### 2.2.3 健康档案

**宠物档案创建：**
- 基础信息：昵称、品种、性别、生日、体重
- 照片上传
- 绝育状态
- 芯片编号（如有）
- 过敏史
- 遗传病史

**自动记录：**
- 每次问诊自动生成病历
- 每次预约就诊自动记录
- 疫苗、驱虫手动录入或扫描录入

**健康提醒：**
- 基于档案数据智能计算提醒时间
- 推送通知
- 日历展示

**健康分析：**
- AI 分析健康数据
- 生成健康评分
- 提供个性化护理建议

#### 2.2.4 医院与医生信息

**医院信息：**
- 基础信息：名称、地址、电话、营业时间
- 资质认证：营业执照、动物诊疗许可证
- 科室列表
- 医生团队
- 环境照片
- 用户评价
- 价格公示

**医生信息：**
- 基础信息：姓名、照片、职称
- 资质证书：执业兽医师资格证
- 专业背景：毕业院校、工作经历
- 擅长领域
- 接诊量统计
- 用户评价

#### 2.2.5 价格透明化

**价格展示原则：**
- 问诊费：明码标价（如图文问诊 30-50元，视频问诊 80-120元）
- 挂号费：明确显示
- 常规项目：疫苗、驱虫、绝育等标准化项目明码标价
- 诊疗费：给出价格区间或参考价
- 套餐服务：打包优惠价格

**价格对比：**
- 同城医院价格对比
- 全国平均价格参考

### 2.3 特色功能

#### 2.3.1 AI 智能助手
- **症状自检**：通过问答和图片识别初步判断
- **智能推荐医生**：基于症状、评价、距离等多维度推荐
- **智能健康分析**：分析健康档案，给出风险提示

#### 2.3.2 紧急服务
- **急诊指引**：根据定位推荐最近的24小时急诊医院
- **急诊绿色通道**：快速预约
- **中毒查询**：食物中毒、药物中毒快速查询

#### 2.3.3 健康知识库
- 按品种分类的护理知识
- 常见疾病百科
- 疫苗驱虫指南
- 急救知识

#### 2.3.4 社区功能（轻量化）
- 仅在医生主页提供"经验分享"
- 用户可在评价中分享就诊经历
- 不做独立社区模块，避免功能分散

## 三、用户体验设计

### 3.1 界面设计原则

**设计风格：**
- **简洁清爽**：白色/浅色背景，避免花哨
- **专业可信**：医疗场景用色克制，建立信任感
- **温暖友好**：宠物场景可适当活泼，圆角设计
- **清晰易读**：文字层级清晰，重要信息突出

**色彩方案：**
- **主色调**：#4A90E2（信赖蓝）- 专业、可信赖
- **辅助色**：#50C878（生机绿）- 健康、活力
- **强调色**：#FF6B6B（警示红）- 紧急、提醒
- **中性色**：#F5F5F5（背景灰）、#333333（文字黑）

### 3.3 交互设计要点

#### 3.3.1 快速操作
- **首页直达**：核心功能（问诊、预约）首页大按钮直达
- **一键拨号**：医院详情页可直接拨打电话
- **一键导航**：集成地图导航
- **快速填写**：自动关联宠物档案，减少重复填写

#### 3.3.2 信任建立
- **资质展示**：医院、医生资质证书可点击查看大图
- **认证标识**：认证医院/医生显著标识
- **评价真实**：仅已就诊用户可评价
- **价格透明**：价格明细清晰展示

#### 3.3.3 贴心提醒
- **推送通知**：疫苗、体检、预约提醒
- **智能提醒**：基于档案数据自动计算提醒时间
- **提前提醒**：预约前1天、1小时分别提醒

#### 3.3.4 流畅体验
- **加载优化**：图片懒加载，骨架屏
- **离线功能**：健康档案支持离线查看
- **快速响应**：界面交互流畅，无明显卡顿

## 四、技术架构建议

### 4.1 客户端技术栈

**移动端（建议方案）：**
- **跨平台框架**：Flutter 或 React Native
  - 优点：一套代码，iOS/Android双平台
  - 适合初创团队，快速迭代

**备选方案：**
- **原生开发**：Swift (iOS) + Kotlin (Android)
  - 优点：性能最优，体验最佳
  - 缺点：开发成本高

### 4.2 核心功能技术方案

#### 4.2.1 实时通讯（问诊）
- **方案**：WebSocket + WebRTC
- **即时通讯**：图文消息使用 WebSocket
- **视频通话**：使用 WebRTC
- **第三方服务**：考虑融云、环信、腾讯云 IM

#### 4.2.2 地图定位
- **方案**：高德地图 SDK / 百度地图 SDK
- **功能**：定位、搜索附近医院、导航

#### 4.2.3 支付
- **方案**：微信支付 + 支付宝
- **场景**：问诊费、预约挂号、服务套餐

#### 4.2.4 推送通知
- **方案**：
  - iOS：APNs
  - Android：极光推送 / 友盟推送
- **场景**：健康提醒、预约提醒、医生回复提醒

#### 4.2.5 图片处理
- **上传**：七牛云 / 阿里云 OSS
- **压缩**：客户端压缩后上传
- **展示**：CDN 加速

### 4.3 后端架构

**技术栈建议：**
- **语言**：Node.js / Python (Django/FastAPI) / Java (Spring Boot)
- **数据库**：
  - 主库：PostgreSQL / MySQL
  - 缓存：Redis
  - 文档存储：MongoDB（用于病历等非结构化数据）
- **消息队列**：RabbitMQ / Kafka
- **搜索**：Elasticsearch（医院、医生搜索）

**微服务划分：**
- 用户服务
- 问诊服务
- 预约服务
- 健康档案服务
- 支付服务
- 通知服务
- 搜索服务

### 4.4 数据安全
- **隐私保护**：遵守《个人信息保护法》
- **数据加密**：传输加密（HTTPS）、存储加密
- **权限控制**：用户数据严格权限管理
- **医疗数据**：符合医疗数据合规要求

## 五、运营策略

### 5.1 冷启动策略

**医院端：**
1. **线下BD**：重点城市优质医院合作
2. **利益绑定**：免费入驻、流量扶持
3. **培训支持**：帮助医院数字化转型

**医生端：**
